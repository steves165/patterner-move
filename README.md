# Patterner move

Weave, Knit and Sew Patterner moved from `steves165.github.io/weave-patterner` to [weave-patterner.com](https://weave-patterner.com/).
Browsers keep saved data per site, so this page (which shares the old address's storage) reads the patterns and settings
saved there and hands them to the app at the new address that opened it. Nothing is sent to any server.

The source lives in [steves165/weave-patterner](https://github.com/steves165/weave-patterner) at `move/index.html`.
